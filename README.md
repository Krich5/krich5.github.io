# KR Studio

KR Studio’s GitHub Pages homepage for Webex Contact Center and UCCX tools.

Live site: https://krich5.github.io/

Static HTML and SVG, with no build step or external dependencies. Edit the cards in `index.html` to add projects or update links.

Agent Desktop Tools are grouped on `agent-desktop.html`, linked from the main landing page. Both pages include navigation back to the toolbox.
